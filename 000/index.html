🎯 Fredagsquiz med AI

En levande beskrivning av processen att skapa pedagogiska quiz tillsammans med generativ AI

Varför AI för quiz-skapande?

Sedan mitten av augusti 2025 har ekonom Kent Lundgren varje vecka skapat pedagogiska och engagerande fredagsquiz med hjälp av generativ AI. Denna sida beskriver den kreativa processen bakom veckans quiz - från idé till färdig produkt.

📝 En tvåstegsprocess med två AI-verktyg

Skapandet av veckans fredagsquiz bygger på en genomtänkt arbetsprocess där två olika AI-verktyg används i samarbete - vardera med sina styrkor.

Steg 1

🤖 Claude - Innehållsskaparen

Prompt 1: Konceptualisering och innehållsgenerering

📂 Prompten finns i tre format - välj det som passar dig:

📄
PDF-format

Bäst för läsning: Bevarar all formatering, ser likadant ut överallt. Perfekt om du vill läsa igenom prompten för att förstå innehållet.

👥 Rekommenderad för människor som vill läsa
📝
Word-format (.docx)

Bäst för redigering: Lätt att öppna, kopiera delar av texten, göra ändringar och återanvända i andra sammanhang. Perfekt om du vill skapa din egen variant.

✏️ Rekommenderad för människor som vill redigera
💻
Markdown-format (.md)

Bäst för AI: Ren text med enkel formatering som AI-verktyg kan läsa direkt. Detta är formatet som gjorde att Cursor kunde läsa och analysera prompten.

🤖 Rekommenderad för AI-verktyg

💡 Viktigt att förstå: Samma innehåll i alla tre format, men varje format har sitt syfte:

  • PDF = Vacker läsning för människor
  • Word = Flexibel redigering för människor
  • Markdown = Optimal bearbetning för AI

Den första prompten skickas till Claude för att skapa quiz-innehåll. Här är ett faktiskt exempel från veckans fredagsquiz:

📋 Utdrag från den verkliga prompten (promt1_till_251121.md):

Ämne: Årsbokslut och årsredovisning 2025

Roll: "Du är en ekonom, controller, som är bra på ekonomistyrning, årsbokslut och årsredovisning, i en svensk kommun - Simrishamns kommun."

Analysbehov: "Du ska analysera och beskriva årsbokslut och årsredovisning väl och utförligt för dem som inte tydligt ser skillnaden mellan årsbokslut och årsredovisning."

Slutprodukt: "Dessa fem slides, ska sen i sin tur vara underlag till ett quiz bestående av fem frågor med fyra alternativa svar. Detta quiz ska vara klurigt, spännande, kul och lärorikt."

Källor: "Du ska referera till källor enligt Harvadformatet, dvs med Harvardstil."

Vad händer i detta steg?
  1. Temaval: Kent definierar ämnet (t.ex. årsbokslut vs årsredovisning)
  2. Kontext: Bifogade dokument och specifika krav anges (Harvardstil, 5 frågor, etc.)
  3. Strukturering: Claude skapar:
    • Utförlig bloggtext (faktabas)
    • 5 koncentrerade slides
    • 5 quiz-frågor med 4 svarsalternativ var
    • Utförliga motiveringar med källhänvisningar
  4. Output: Komplett innehåll i Markdown-format, klart för steg 2
🎯 Specifika krav i denna prompt:
  • Målgrupp: Enhetschefer och ekonomer i kommunal verksamhet
  • Pedagogik: "Klurigt, spännande, kul och lärorikt"
  • Struktur: Blogg → Slides → Quiz (trattformad pedagogik)
  • Källor: Internet-research + bifogade dokument
  • Format: Harvardstil för referenser
  • Viktiga datum: Tidplan från Simrishamns kommun inkluderad
💪 Claudes styrkor för detta arbete:
  • Kan läsa och analysera bifogade dokument (när de är i Markdown!)
  • Omfattande kunskapsbas inom ekonomi och kommunal förvaltning
  • Söker information på internet för jämförelser
  • Skapar strukturerat innehåll i flera lager (blogg → slides → quiz)
  • Hanterar komplexa instruktioner om format och källhänvisning
  • Kvalitetssäkrad svensk språkbehandling

Den andra prompten skickas till Cursor för att omvandla innehållet till en interaktiv webbapplikation. Här är faktiska instruktioner från prompten:

📋 Utdrag från den verkliga prompten (promt2_till_251121.md):

Filstruktur: "Du skapar ett nytt quiz i: index.html, script.js och styles.css"

Återanvändning: "Jag vill att du i princip återanvänder samma programmeringsteknik som finns i quiz.html-filen"

Innehåll: "Jag vill att du läser igenom den texten först [bloggen]. Förslag på fem frågor finns nedan (men jag vill att du analyserar frågorna, och om du finner det möjligt och önskvärt ska du göra frågorna än bättre, tydligare och roligare)"

Bilder: "Jag vill att du i stället för den bild som finns i quiz.html har bilderna: arsredovisning_2021.jpg och arsredovisning_2024.jpg"

Källor: "Referenser och källor ska anges med Harvardstil, dvs i Harvardformat. Se till att källorna i största möjliga mån är klickbara"

Vad händer i detta steg?
  1. Input från Claude: De 5 slides och 5 quiz-frågor från steg 1
  2. Återanvändning: Cursor använder existerande quiz.html som mall för struktur
  3. Anpassning:
    • Byter ut innehåll till nytt ämne (årsbokslut/årsredovisning)
    • Uppdaterar bilder (arsredovisning_2021.jpg, arsredovisning_2024.jpg)
    • Implementerar klickbara källor i Harvardformat
    • Säkerställer responsiv design för mobil och desktop
  4. Funktionalitet: Slides → Quiz → Poängräkning → Resultat med motiveringar
  5. Output: Tre separata filer (index.html, script.js, styles.css)
🎯 Specifika tekniska krav i denna prompt:
  • Separering: HTML, CSS och JavaScript i olika filer
  • Bevara original: "quiz.html, script_quiz.js och styles_quiz.css ska hela tiden vara oförändrade"
  • Responsivitet: "Anpassar slides och frågor så att de passar både på dator och mobil"
  • Interaktivitet: Användare trycker på knapp för att gå vidare till quiz
  • Källor: Klickbara länkar i Harvardformat
  • Komplexitet: Prompten innehåller alla 5 slides OCH alla 5 frågor med utförliga motiveringar (475 rader!)
💪 Cursors styrkor för detta arbete:
  • Kan läsa existerande quiz.html och återanvända struktur
  • Kan läsa Markdown-prompten direkt (inte PDF/Word!)
  • Ser hela projektet - vet vilka filer som finns och ska bevaras
  • Genererar ren kod uppdelad i HTML, CSS och JavaScript
  • Implementerar responsiv design automatiskt
  • Skapar interaktiva element med moderna webbstandarder
  • Följer best practices för tillgänglighet
💡 En viktig insikt om Markdown:

Eftersom prompten är i Markdown-format kan Cursor:

  • ✅ Läsa hela prompten direkt (475 rader)
  • ✅ Se strukturen tydligt (rubriker, listor, kodblock)
  • ✅ Extrahera de 5 slides och 5 frågorna korrekt
  • ✅ Förstå formateringen (fetstil, kursiv, länkar)

Om det hade varit PDF: ❌ Endast binär data → omöjligt att läsa → processen hade inte fungerat!

🔧 Praktisk guide: Konvertera PDF/Word till Markdown

Eftersom både PDF och Word är binära format som är svåra för AI att läsa, behöver du konvertera dem till Markdown. Här är flera sätt att göra det:

Metod 1: Online-konverterare (Enklast)

📄 PDF till Markdown:

  • PDF2MD - Dra och släpp PDF, få Markdown tillbaka
  • Convertio - Stöder många format inklusive PDF → MD
  • Aspose - Gratis online-konvertering

📝 Word (.docx) till Markdown:

  • Word2MD - Specialiserad på Word till Markdown
  • CloudConvert - Stöder DOCX → MD med bra formatering
  • Pandoc Online - Via webbgränssnitt (se metod 2)
Steg-för-steg:
  1. Gå till någon av webbplatserna ovan
  2. Ladda upp din PDF eller Word-fil
  3. Välj "Markdown" (.md) som utformat
  4. Klicka "Konvertera"
  5. Ladda ner den färdiga Markdown-filen
💡 Tips: Online-verktyg är snabbast för enstaka filer, men tänk på att inte ladda upp känsliga dokument till okända tjänster!

Metod 2: Pandoc (Rekommenderat för många filer)

Pandoc är ett kraftfullt kommandoradsverktyg som kallas "den schweiziska armékniven för dokumentkonvertering".

Installation i PowerShell (Windows):

# Med Chocolatey (om du har det installerat)
choco install pandoc

# Eller ladda ner från:
# https://pandoc.org/installing.html

Användning:

# Konvertera Word till Markdown
pandoc promt1_till_251121.docx -o promt1_till_251121.md

# Konvertera PDF till Markdown (kräver extra installation)
pandoc promt1_till_251121.pdf -o promt1_till_251121.md

# Konvertera alla Word-filer i en mapp
Get-ChildItem *.docx | ForEach-Object { pandoc $_.Name -o "$($_.BaseName).md" }
💡 Tips: Pandoc är perfekt om du har många filer att konvertera eller vill automatisera processen!

Metod 3: Manuell kopiering (För kortare dokument)

För kortare dokument kan det vara snabbast att manuellt skapa en Markdown-fil:

Steg-för-steg:
  1. Öppna din PDF/Word-fil och kopiera texten
  2. Öppna en texteditor (t.ex. Notepad, VS Code, Cursor)
  3. Klistra in texten
  4. Lägg till Markdown-formatering manuellt:
    • # Rubrik 1 för huvudrubriker
    • ## Rubrik 2 för underrubriker
    • **fetstil** för fetstil
    • *kursiv* för kursiv
    • - punkt för punktlistor
    • 1. punkt för numrerade listor
  5. Spara filen med ändelsen .md
Exempel på Markdown-formatering:
# Prompt 1: Skapa Fredagsquiz

## Syfte
Skapa ett engagerande quiz om ekonomi med **10 frågor**.

## Krav
- Varierande svårighetsgrad
- Pedagogiska förklaringar
- Svenska språket

### Målgrupp
Quizet riktar sig till *allmänheten* med intresse för ekonomi.

Metod 4: Använd AI för konvertering (Smart!)

Moderna AI-verktyg som Claude och ChatGPT kan ofta läsa PDF och Word-filer direkt!

Hur det fungerar:

  1. Gå till Claude.ai eller ChatGPT
  2. Ladda upp din PDF eller Word-fil (använd 📎-ikonen)
  3. Skriv prompt: "Konvertera detta dokument till Markdown-format"
  4. Kopiera resultatet till en ny .md-fil
🤖 AI-verktyg som kan läsa dokument:
  • Claude (Anthropic) - Läser PDF och bilder direkt
  • ChatGPT Plus - Stöder många filformat
  • Google Gemini - Kan analysera PDF-filer

⚠️ Obs: Gratis-versionerna har ofta begränsningar för filuppladdning.

💡 Tips: Detta är ofta den bästa metoden eftersom AI:n kan behålla struktur och till och med förbättra formateringen!

Filformat: PDF vs Word - En teknisk analys

🔍 Utmaningen

När underlagsfiler behöver bifogas och analyseras av AI-verktyg uppstår frågan: Vilket filformat är bäst - PDF eller Word (.docx)?

📄 PDF (Portable Document Format)

Fördelar:
  • ✅ Universell kompatibilitet - Ser likadant ut överallt
  • ✅ Bevarar formatering - Layout och typografi bibehålls exakt
  • ✅ Säkerhet - Svårare att oavsiktligt ändra innehåll
  • ✅ Mindre filstorlek - Ofta mer komprimerad
  • ✅ Professionell standard - Accepterat format för publicering
Nackdelar:
  • ❌ Svår textextraktion - AI har svårare att läsa innehållet
  • ❌ Binärt format - Inte direkt läsbar som text
  • ❌ Komplex struktur - Kräver specialiserade verktyg för parsing
  • ❌ Begränsad redigerbarhet - Svårt att göra snabba ändringar

📝 Word (.docx)

Fördelar:
  • ✅ Lätt att redigera - Kan enkelt ändras och uppdateras
  • ✅ Strukturerad data - XML-baserat format
  • ✅ Metadata - Innehåller trackad information om ändringar
  • ✅ Samarbetsvänligt - Enkel att dela och kommentera
Nackdelar:
  • ❌ Fortfarande binärt - Inte direkt läsbar som ren text
  • ❌ Versionsproblem - Olika Word-versioner kan visa olika resultat
  • ❌ Större filstorlek - Ofta mer data än nödvändigt
  • ❌ Proprietärt - Kräver Microsoft-ekosystem för bästa upplevelse

💡 Den tekniska verkligheten

Problemet: Både PDF och Word (.docx) är binära format som inte kan läsas direkt som text av många AI-verktyg, inklusive de som används i Cursor.

Vad innebär det?

  • När man försöker läsa en PDF eller Word-fil med standard read-verktyg får man binär data (1:or och 0:or) istället för läsbar text
  • Specialiserade parsers krävs för att extrahera text från dessa format
  • Formatering, bilder och layout komplicerar textextraktion ytterligare

🎯 Vad är då bäst?

Rekommendation för AI-arbete:

MARKDOWN (.md) eller REN TEXT (.txt) är klart bäst när filer ska analyseras av AI!

Varför Markdown/Text?
  • ✨ Direkt läsbar - AI kan läsa innehållet utan specialverktyg
  • ✨ Enkel struktur - Formatering med enkla tecken (# för rubriker, * för listor)
  • ✨ Versionshantering - Perfekt för Git och samarbete
  • ✨ Liten filstorlek - Minimal overhead
  • ✨ Plattformsoberoende - Fungerar överallt
  • ✨ Framtidssäker - Kommer alltid kunna läsas
När PDF/Word ändå är relevant:
  • 📊 För publicering: PDF för dokument som ska delas med slutanvändare
  • 📝 För redigering: Word när många personer ska samarbeta
  • 🎨 För design: När layout och visuell presentation är kritisk

✅ Best Practice för AI-projekt

  1. Arbetsformat: Använd Markdown för dokument som AI ska läsa
  2. Publiceringsformat: Konvertera till PDF för slutanvändare
  3. Redigeringsformat: Använd Word endast när mänsklig samarbete kräver det
  4. Versionskontroll: Lagra alltid en textbaserad version (Markdown) i Git

🐍 PRAKTISK LÖSNING: Läsa PDF-filer direkt i Cursor med Python

Nyhet! Även om Cursor inte kan läsa PDF-filer direkt, kan vi använda en parser för att göra dem läsbara!

🔍 Vad är en "parser"?

En parser är ett program som:

  1. Läser en fil med komplex struktur (som PDF)
  2. Tolkar och förstår strukturen (text, bilder, layout)
  3. Extraherar den information som behövs (t.ex. bara texten)
  4. Ger tillbaka datan i ett användbart, läsbart format

💡 Analogi: Tänk dig en PDF som en täckt chokladkaka. Parsern är verktyget som tar bort papperet och folien så du kan komma åt chokladen (texten) inuti.

⚙️ Hur vi implementerade PDF-läsning i detta projekt

Steg 1: Kontrollera Python
python --version

✅ Resultat: Python 3.13.2 installerat

Steg 2: Installera PyPDF2 (parsern)
pip install PyPDF2

✅ PyPDF2 är en Python-modul specialiserad på att läsa PDF-filer

Steg 3: Skapa Python-skript (read_pdf.py)

Ett enkelt skript som:

  • Tar emot en PDF-fil som argument
  • Använder PyPDF2 för att öppna och läsa filen
  • Extraherar text från alla sidor
  • Visar texten i terminalen
Steg 4: Använd skriptet
python read_pdf.py promt1_till_251121.pdf

✅ Resultat: Läsbar text från PDF:en!

⚠️ Begränsningar och alternativ

Begränsningar med PyPDF2:
  • Fungerar bäst med textbaserade PDF:er
  • Tabeller kan bli missformade
  • Bilder extraheras inte (endast text)
  • Komplexa layouter kan bli svåra att tolka
Alternativa Python-parsers:
Parser Styrka Användning
PyPDF2 Enkel, grundläggande pip install PyPDF2
pdfplumber Bättre för tabeller pip install pdfplumber
PyMuPDF (fitz) Snabb, kraftfull pip install PyMuPDF
Camelot Specialiserad på tabeller pip install camelot-py
