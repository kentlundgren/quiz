🔧 Teknisk beskrivning

Struktur och organisation

Filstruktur: Detta quiz är byggt med separation av concerns-principen, där HTML, CSS och JavaScript är uppdelade i separata filer:

  • index.html: Innehåller HTML-strukturen och semantisk markup
  • styles.css: All styling och responsiv design
  • script.js: All JavaScript-logik och interaktivitet
💡 Varför separata filer?

Att dela upp kod i separata filer ger flera fördelar:

  • Underhållbarhet: Lättare att hitta och uppdatera specifik kod
  • Återanvändbarhet: CSS och JavaScript kan användas i flera HTML-filer
  • Läsbarhet: Tydligare struktur och mindre filer att hantera
  • Cachning: Webbläsaren kan cacha CSS och JS separat för bättre prestanda
  • Samarbete: Flera utvecklare kan arbeta med olika filer samtidigt
  • Best practice: Följer webbutvecklingens standarder och konventioner

Teknisk implementation

  • HTML5: Semantisk markup med ARIA-attribut för tillgänglighet
  • CSS3: Responsiv design med CSS-variabler och flexbox
  • JavaScript (ES6+): Modern JavaScript med arrow functions, template literals och DOM-manipulation
  • UI: Progressbar, sidindikator med klickbara prickar, växlande bilder
  • Bildväxling: Automatisk växling mellan Simrishamn.jpg och Tomelilla_station.jpg var 3:e sekund
  • Interaktion: Val med färgkodning (grön/röd), gul bakgrund på inputfält (regel 18)
  • Responsivitet: Fungerar på både dator och mobil
