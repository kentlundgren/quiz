🔧 Teknisk beskrivning

Struktur och organisation

Filstruktur: Detta quiz är byggt med separation of concerns-principen, där HTML, CSS och JavaScript är uppdelade i separata filer:

  • index.html: Innehåller HTML-strukturen och semantisk markup
  • styles.css: All styling och responsiv design
  • script.js: All JavaScript-logik och interaktivitet
🆕 NYTT I VERSION 2 - Firebase-integration

Denna version har följande nya funktioner:

  • Namnregistrering: Användaren anger sitt namn innan quizet börjar
  • Svårighetsbetyg: Efter quizet betygsätter användaren svårighetsgraden (1-10)
  • Firebase-lagring: Namn, betyg, poäng och datum sparas i Firebase Realtime Database
  • Firebase SDK v11.0.0: Använder senaste versionen av Firebase
💡 Varför separata filer?

Att dela upp kod i separata filer ger flera fördelar:

  • Underhållbarhet: Lättare att hitta och uppdatera specifik kod
  • Återanvändbarhet: CSS och JavaScript kan användas i flera HTML-filer
  • Läsbarhet: Tydligare struktur och mindre filer att hantera
  • Cachning: Webbläsaren kan cacha CSS och JS separat för bättre prestanda
  • Samarbete: Flera utvecklare kan arbeta med olika filer samtidigt
  • Best practice: Följer webbutvecklingens standarder och konventioner

Teknisk implementation

  • HTML5: Semantisk markup med ARIA-attribut för tillgänglighet
  • CSS3: Responsiv design med CSS-variabler och flexbox
  • JavaScript (ES6+): Modern JavaScript med arrow functions, template literals och DOM-manipulation
  • Firebase v11.0.0: Realtime Database för datalagring
  • UI: Progressbar, sidindikator med klickbara prickar, växlande bilder
  • Bildväxling: Automatisk växling mellan två bilder var 3:e sekund
  • Interaktion: Val med färgkodning (grön/röd), gul bakgrund på svarsalternativ
  • Responsivitet: Fungerar på både dator och mobil

🔥 Vad är Firebase?

📜 Historia
  • 2011: Firebase grundades av James Tamplin och Andrew Lee i San Francisco
  • 2012: Lanserade sin första produkt – Realtime Database
  • 2014: Google köpte Firebase för uppskattningsvis 100+ miljoner dollar
  • 2016: Google integrerade Firebase med sin molnplattform och utökade kraftigt
  • Idag: Firebase är en av världens mest populära Backend-as-a-Service (BaaS) plattformar

Ägare: Google (Alphabet Inc.) sedan 2014. Del av Google Cloud Platform.

📊 Hur fungerar Firebase Realtime Database?

Firebase använder JSON-träd (inte tabeller som SQL-databaser). Så här ser datastrukturen ut:

borgholm-registration/
├── quiz-resultat/
│   └── fritidskortet-kulturskolan/
│       ├── 1765307080277/
│       │   ├── namn: "Anna"
│       │   ├── svårighetsgrad: 7
│       │   └── poäng: "4 av 5"
│       └── ...
└── borgholm-test/
    └── persons/
⚡ Realtidssynkronisering
  • Data synkroniseras automatiskt till alla anslutna klienter
  • Använder WebSocket för snabb kommunikation
  • Perfekt för appar som behöver live-uppdateringar (chat, spel, quiz)

👍 Fördelar med Firebase

  • Ingen backend-kod behövs – JavaScript i webbläsaren räcker
  • Snabb att komma igång – Fungerar på minuter
  • Automatisk skalning – Google hanterar infrastrukturen
  • Bra dokumentation – Mycket tutorials och exempel
  • Generös gratisplan – Räcker för hobbyprojekt och små appar
  • SDK för många plattformar – Web, iOS, Android, Flutter, Unity

👎 Nackdelar med Firebase

  • Vendor lock-in – Svårt att flytta till annan plattform
  • Prismodell kan bli dyr – Vid stor skala ökar kostnaderna snabbt
  • Begränsade queries – Inte lika kraftfullt som SQL
  • NoSQL-struktur – Kräver annorlunda tänk än relationsdatabaser
  • Säkerhetsregler – Kan vara knepiga att konfigurera rätt
🔐 Säkerhet

Databasen har konfigurerats för att tillåta läsning och skrivning utan autentisering. Detta fungerar bra för ett publikt quiz, men för känslig data bör striktare säkerhetsregler användas i Firebase Console under "Rules".

🔧 Teknisk koppling i detta quiz

Så här fungerar det:
  1. Firebase SDK v11.0.0 laddas via CDN från Google
  2. Konfiguration kopplar till projektet "borgholm-registration"
  3. Realtime Database lagrar data i JSON-format
  4. WebSocket möjliggör realtidsuppdateringar
  5. Data sparas under sökvägen: quiz-resultat/fritidskortet-kulturskolan/
