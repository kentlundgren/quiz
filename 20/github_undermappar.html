🌳 GitHub Trädstrukturer

Hur Mappar och Filer Organiseras i Git och GitHub

📁 Introduktion: Vad är en Trädstruktur?

En trädstruktur (tree structure) är det sätt som Git och GitHub organiserar filer och mappar i ett repository. Precis som filsystemet på din dator har GitHub en hierarkisk struktur där:

  • Root (roten) - den översta nivån i ditt repository
  • Mappar/kataloger - kan innehålla filer och andra mappar
  • Filer - det faktiska innehållet (HTML, CSS, JS, bilder, etc.)

💡 Varför kallas det "träd"?

Namnet kommer från att strukturen liknar ett träd:

  • Stammen = Root-mappen (huvudkatalogen)
  • Grenarna = Undermappar
  • Löven = Filer

🔗 Hur URL:er Mappas till Trädstrukturen

GitHub använder en logisk och förutsägbar URL-struktur som direkt speglar filsystemets trädstruktur:

Grundläggande URL-struktur

https://github.com/användarnamn/repository/tree/branch/sökväg
URL-del Beskrivning Exempel
användarnamn Ditt GitHub-användarnamn kentlundgren
repository Namnet på ditt repo quiz
branch Gren (vanligen "main") main
sökväg Mapp/fil-sökväg i repot 20/index.html

Konkreta exempel från Fredagsquiz:

1. Root-nivån (huvudkatalogen)

https://github.com/kentlundgren/quiz/tree/main

Visar innehållet i huvudkatalogen (root) på main-grenen.

2. Mapp 0 (översiktssida)

https://github.com/kentlundgren/quiz/tree/main/0

Visar innehållet i undermappen "0" - översiktssidan för alla quiz.

3. Mapp 20 (dagens quiz)

https://github.com/kentlundgren/quiz/tree/main/20

Visar innehållet i undermappen "20" - quizet om synundersökningar.

4. En specifik fil

https://github.com/kentlundgren/quiz/blob/main/20/README.md

Observera: För filer används /blob/ istället för /tree/!

⚠️ Viktigt att notera:

  • /tree/ används för mappar
  • /blob/ används för filer

🌐 GitHub Pages - Hur Live-versionen Fungerar

När du aktiverar GitHub Pages för ditt repository skapas automatiskt en webbplats där trädstrukturen blir till faktiska webbadresser:

GitHub Repository → GitHub Pages (Live)
github.com/kentlundgren/quiz/tree/main → kentlundgren.github.io/quiz/
github.com/kentlundgren/quiz/tree/main/0 → kentlundgren.github.io/quiz/0/
github.com/kentlundgren/quiz/tree/main/20 → kentlundgren.github.io/quiz/20/
github.com/kentlundgren/quiz/blob/main/20/index.html → kentlundgren.github.io/quiz/20/index.html

✅ Automatisk URL-generering

GitHub Pages gör automatiskt följande:

  • Tar bort /tree/main/ från sökvägen
  • Tar bort /blob/main/ från sökvägen
  • Använder din användare och repo-namn som domän
  • Serverar index.html automatiskt när du besöker en mapp

💡 Viktiga Principer för GitHub Trädstrukturer

1. Varje mapp är självständig

Varje undermapp (0/, 1/, 2/, ... 20/) fungerar som en självständig "mini-webbplats" med sina egna filer:

  • index.html - startsida för mappen
  • README.md - dokumentation för mappen
  • Egna CSS/JS-filer
  • Egna bilder och resurser

2. README.md visas automatiskt

När du besöker en mapp på GitHub (t.ex. /tree/main/20) så visas innehållet i README.md automatiskt under fillistan. Detta gör det enkelt att:

  • Dokumentera vad mappen innehåller
  • Ge instruktioner för hur man använder filerna
  • Länka till relaterade resurser

3. Relativa vs Absoluta sökvägar

Relativa sökvägar (rekommenderat inom samma repo):

<a href="../0/">Till översiktssidan</a> <a href="../20/">Till quiz 20</a> <img src="synundersokning1.jpg"> <!-- Bild i samma mapp -->

Absoluta sökvägar (för externa länkar):

<a href="https://kentlundgren.github.io/quiz/20/">Quiz 20</a> <a href="https://github.com/kentlundgren/quiz">GitHub Repo</a>

4. Namnkonventioner

⚠️ Viktiga regler för mappnamn:

  • Använd enkla namn (siffror, bokstäver, bindestreck)
  • Undvik mellanslag - använd bindestreck: quiz-20 istället för quiz 20
  • Undvik svenska tecken (å, ä, ö) i mappnamn
  • Använd små bokstäver för konsekvens
  • GitHub är skiftlägeskänsligt: Quiz/ ≠ quiz/

🔍 Så Hittar du Runt i Strukturen

På GitHub (källkod):

  1. Börja på root: github.com/kentlundgren/quiz
  2. Klicka på mappar för att navigera djupare
  3. Använd "breadcrumbs" högst upp för att gå tillbaka
  4. Läs README.md i varje mapp för information

På GitHub Pages (live-version):

  1. Börja på: kentlundgren.github.io/quiz/
  2. Lägg till mappnamn i URL:en: /0/, /20/, etc.
  3. Varje mapp serverar sin index.html automatiskt
  4. Använd navigeringslänkar i quizen

✅ Nyckeln till Förståelse

Tänk på GitHub som ett filsystem:

  • Root (/) = Huvudkatalogen
  • Mappar = Underkataloger med eget innehåll
  • Filer = Det faktiska innehållet
  • GitHub Pages = Gör mappstrukturen till en webbplats

URL:en speglar alltid den exakta sökvägen i filsystemet!

🎯 Praktiska Tips

För att skapa en ny undermapp (t.ex. quiz 21):

  1. Skapa en ny mapp: 21/
  2. Lägg till filer: index.html, script.js, styles.css, README.md
  3. Commita och pusha till GitHub
  4. Mappen blir automatiskt tillgänglig på:
    • GitHub: github.com/kentlundgren/quiz/tree/main/21
    • GitHub Pages: kentlundgren.github.io/quiz/21/
  5. Uppdatera översiktssidan i mapp 0 med länk till det nya quizet

För att länka mellan quiz:

<!-- Från quiz 20 till översiktssidan (mapp 0) --> <a href="../0/">Se alla quiz</a> <!-- Från quiz 20 till quiz 1 --> <a href="../1/">Till Quiz 1</a> <!-- Till GitHub repo --> <a href="https://github.com/kentlundgren/quiz">Källkod</a>

💡 Best Practice

Varje quiz-mapp (1-20+) bör innehålla:

  • README.md - Beskrivning av quizet
  • index.html - Själva quizet
  • script.js - JavaScript-logik
  • styles.css - Styling
  • Länkar tillbaka till mapp 0 (översikten)
  • Länkar till GitHub repo
